# denki-demo — 電設ボード（電気工事業 仕組み化デモ）

電気工事会社向けの業務仕組み化提案で使う、実際に操作できるデモ。
土木版（`doboku-demo`）の骨格を引き継ぎつつ、電気工事に固有の論点を中心に組み直したもの。

## 入っているもの

- 見積積算（工事テンプレ × 得意先区分 × 台数・回路数・延長）→ 受注登録 → 工程自動生成 → 人員・資格配置 → 出来高入力 → 請求書PDF発行 → 入金消込
- **得意先区分ごとの単価表を画面上で編集できる**（個人宅／法人・店舗／法人・工場／元請下請）。直すと見積・請求書・粗利まで即座に通る
- 2週間ガント／月カレンダーの切替、横断検索、スワイプ送り、工程のドラッグ編集
- 単一HTML。外部依存は Google Fonts / html2canvas / jsPDF（いずれもCDN）

## 電気工事版で足した論点（土木版にはないもの）

| 論点 | 画面での出方 |
|---|---|
| **区分別単価表** | 05 単価表。材料単価／施工単価／材工共を切り替えて4区分を直接編集。一括±%、原価×掛率での再計算、原価と粗利率の併記 |
| **4区分の見積比較** | 同じ工事を4区分で積算した結果を並べ、「単価表を1本で運用している取りこぼし」を金額で見せる |
| **材料費と施工費の分離** | 夜間・停電作業や休日の割増が**施工費にだけ**掛かる。材料に割増を乗せる誤りが構造的に起きない |
| **法定福利費の明示** | 施工費の 18.5% を内訳に自動計上し、請求書にも明示（建設業の法定福利費内訳明示に対応） |
| **資格による配置制約** | 高圧は第一種、自火報は消防設備士。二重割当と**資格不足**を同時に判定し、該当資格を持つ班を提示 |
| **申請・届出の期限監視** | 電力会社受電申請・系統連系・消防届出・フロン回収手配などを着工日から逆算してアラート。日程を動かすと期限も一緒に動く |
| **点検・更新提案のストック化** | 仕組み化マップに、工事台帳から更新サイクルを引いてリピート受注につなげる論点を追加 |

## 工事テンプレート（10種）

LED照明改修／分電盤交換・単三化／コンセント・スイッチ増設／業務用エアコン入替＋専用回路／動力設備工事（三相200V）／キュービクル更新（高圧受変電）／防犯カメラ・LAN配線／太陽光＋蓄電池／自動火災報知設備／インターホン・TVアンテナ

## 数字の扱い

**案件名・金額・人名・発行者・口座・許可番号はすべて架空**。請求書には「DEMO 見本」を明示。
単価は業界の一般水準を置いた仮値で、商談後に相手先の実単価表へ差し替える前提。
粗利率は 個人宅 34〜47% / 法人 21〜38% / 元請下請 8〜20% のレンジに置いている。
